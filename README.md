Tile Layers draws tile markers and other overlays beneath your player, other players, and all or selected NPCs using normal RuneLite GPU mode. This release uses public RuneLite APIs and does not require the experimental GPU API or a custom client.

**Character limit** replaces the old crowd cutoff. Instead of switching off in busy areas, it selects up to the configured number of NPCs and other players (default 200), prioritising named NPCs, your opponents, recognised bosses, and other NPCs in combat, then distance. Your character is separate. New characters are introduced gradually; hidden or unavailable models do not block the remaining queue. **Excluded bosses** accepts comma-separated NPC names and wildcards and overrides other NPC selections. Existing opacity, NPC names and player settings retain their stored keys. An explicitly disabled old crowd cutoff stays disabled; other old cutoff values use the new default because the setting's meaning has changed.

Character masking uses current floating-point camera coordinates, footprint-aware heights and each actor's world view. It clips triangles at the near plane, combines overlapping masks without repeatedly reducing opacity, skips work where no overlay pixels are present, and respects scene visibility and render filters. Opaque ground-item geometry in front of a character is checked before clearing overlay pixels there. These are character-mask fixes, not general scenery masking.

**Keep labels and loot on top** defaults on and preserves the old saved key. Supported marker text, NPC names and Shortest Path directions stay above character masks. Ground Items' text, backgrounds, controls and timer pies stay together above the mask while its tile highlights remain underneath. For Loot Filters versions containing [the split overlays](https://github.com/riktenx/loot-filters/pull/218), complete labels, icons, backgrounds, borders and timers render above together. Older unsplit Loot Filters versions retain text-only protection. Turning the checkbox off returns labels to normal masking. The Ground Items adapter relies on its current polygon-based tile rendering. Text already baked into images or drawn outside the delegated Graphics2D overlay is not separately identifiable.

**Only Tile and Marker plugins** defaults on. It covers Ground Markers, Tile Indicators, Line Markers, Radius Markers, Brush Markers, Object Markers, Agility, Better NPC Highlight, NPC Indicators, Ground Items, Loot Filters, Shortest Path and Improved Tile Indicators. Other scene overlays stay above characters. Shortest Path's path styles remain underneath while its directions follow the labels checkbox; its minimap and world-map overlays are unchanged. Labels work with this filter on or off.

The current checkbox names and short hover descriptions are included, including **Draw overlays below self**. Object masking, projectile masking, terrain detection, floor allowances and stair/floor-covering lists are experimental GPU API features and are not part of this release.

Build with `gradlew build`. Dependencies come from official RuneLite releases; use `gradlew -PruneliteVersion=1.13.1 build` to verify against a fixed release. `TileLayersPluginTest` remains the standard development launcher. No replacement RuneLite classes or resources are bundled, and no dependency plugins are modified.
